## About

「そもそも何が問題なのか」から考え直すのが好きです。言われた要件をそのまま作るより、本当に解くべき課題に戻って、使われ続ける形まで持っていくことに力を使っています。

- **課題の再定義** — 例：配信成績の「可視化」の依頼を、「今日、誰に、何を働きかけるか」を支援する仕組みへ考え直す
- **事業と技術の翻訳** — 営業・制作・事業側と話し、要件整理 → 実証 → 実装 → 運用までつなげる
- **試作の速さ** — 知らない領域でも調べて、何を試すかを決め、動くところまで持っていく
- **導入後まで考える** — テスト・変更管理・運用・改善まで含めて設計する

最近は、**Claude Code と Codex を役割で使い分けるマルチエージェント開発**を実務の型にしています。司令役の AI が作業内容から委任先（実装・レビュー・画像生成など）を判断し、委任の結果を記録して振り分けルールを検証する、という回し方です。
